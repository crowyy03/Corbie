# CORBIE — Поправка к спеке №1

Дата: 6 сентября 2026 · Статус: утверждено · **Имеет приоритет над `01_PROJECT_SPEC.md` во всём, что ниже**

Пять изменений структуры и две новые фичи. Всё остальное в спеке остаётся как есть.

---

## Изменение 1. Таб-бар

**Было:** Tasks · Calendar · Wishes · Plans · **Us**
**Стало:** **Today** · Tasks · Calendar · Wishes · **Goals**

Us из таб-бара убран — он дублировался пилюлей в шапке. Остаётся пилюлей справа сверху, с точкой-бейджем, когда внутри есть непрочитанное.

*Порядок изменён относительно устного обсуждения: Today стоит первым, потому что это стартовый таб.*

Иконки: Today — солнце/точка, Tasks — галочка, Calendar — сетка, Wishes — звезда, Goals — флажок.

## Изменение 2. Lists сливаются с Tasks

Отдельной сущности «список» больше нет. Есть **задача с опциональной папкой**.

- Задача может лежать в папке (Shopping, To watch, Places) или не лежать — тогда это обычная задача.
- У задачи по-прежнему опциональны исполнитель, срок, заметка. Добавляется опциональное **место**.
- В шапке Tasks две строки чипсов: владельцы `All · Mine · {Partner} · Free`, ниже папки `All · Shopping · To watch · Places · +`.
- Если в выбранной папке у пунктов есть места — в тулбаре появляется переключатель **List / Map**.
- Шаблоны при создании папки: Shopping, Things to watch, Places to go, Cities, Empty. Shopping — закреплённая, создаётся лениво, имеет свой виджет и кнопку «Clear done».
- Настройка папки «Отмечать может любой / только автор» переносится на папку.

**Обоснование:** и задачи, и пункты списка — это галочки. Два понятия для одного действия заставляли пользователя выбирать, куда писать «купить лампочки».

## Изменение 3. Plans → Goals, внутри появляется подготовка

Раздел переименован в **Goals**. Внутри цели три блока:

1. **Прогресс** — целевая сумма, накоплено, потрачено, осталось, перерасход (как было).
2. **Расходы** — записи с валютой и курсом на момент добавления (как было).
3. **Подготовка** — новый чеклист шагов внутри цели. Пример для «Свадьбы»: собрать документы, отдать ребёнка няне, забрать костюм.

Шаг подготовки: текст + заметка + галочка + **опционально исполнитель и срок**. Если срок задан — шаг появляется в Tasks и в Today с пометкой «из цели: Япония». Без срока живёт только внутри цели и общий список не засоряет.

## Изменение 4. Новый экран Today

Стартовый таб. Собирается из существующих данных, своей сущности не имеет.

Сверху: дата и «1 250 дней вместе» одной строкой.

Блоки, каждый рендерится только при непустом содержимом:
- **Today** — события дня и задачи со сроком сегодня, вперемешку по времени, с кружком владельца
- **Free tasks** — неразобранные свободные задачи с кнопкой «Take»
- **Coming up** — 2–3 ближайшие даты; если до дня рождения ≤14 дней и подарок не выбран, строка подсвечена и ведёт в People
- **Goal** — цель с ближайшим дедлайном, полоска прогресса
- **Waiting for you** — капсула готова открыться, голосование без ответа, партнёр добавил хотелку
- **Week recap** — воскресным вечером и до утра понедельника

Пустое состояние: «Nothing on today» + три быстрых действия (добавить задачу, добавить дату, пригласить партнёра).

Today и большой виджет `OurDay` обязаны показывать одно и то же — общий провайдер данных.

## Изменение 5. Us остаётся пилюлей

Открывается по тапу на пилюлю, показывается модально. Внутри: счётчики, Capsules, Vote, People, Settings.

**Бейдж на пилюле** (точка цвета `ice`) при любом из: капсула готова к открытию, есть неотвеченное голосование, партнёр добавил хотелку с прошлого визита, радар подарков активен.

---

## Новая фича A. «Когда мы оба свободны»

Кнопка в тулбаре Календаря → модальный экран.

**Как работает.** Каждое устройство читает **свой** системный календарь через EventKit и публикует в пространство только **анонимные интервалы занятости** — «занят 14:00–15:30», без названий и деталей. Плюс к ним добавляются события Corbie. Партнёр видит, когда ты занят, но не чем.

**Экран.** Диапазон (следующие 7 / 14 дней), фильтры «Evenings / Weekends / 2+ hours», список: «Thu, Sep 10 · after 7:00 PM», «Sat, Sep 12 · all day». Тап по слоту → создание события с предзаполненным временем у обоих.

**Приватность.** Тумблер в настройках «Share my busy times», по умолчанию **выключен**, предлагается прямо на экране при первом входе. Выключил — твои интервалы стираются из пространства. Никогда не публикуем названия, участников, места.

**Обновление.** При выходе приложения на передний план, не чаще раза в час, плюс по `EKEventStoreChanged`. Горизонт — 14 дней вперёд. Старые интервалы чистятся.

**Премиум:** да (после триала — пейволл).

## Новая фича B. Воскресный итог недели

Локальное уведомление в **воскресенье 19:00** по местному времени (отключаемое, тип №10 в настройках) + карточка в Today до утра понедельника.

**Содержание:** сколько задач закрыл каждый (два числа с кружками), движение по целям («Japan +€300, 48%»), что на следующей неделе (даты и события), добавленные хотелки, счётчик дней вместе. Всё считается из существующих данных.

**Бесплатно** — это механизм возврата, за него не платят.

Карточка-шер из итога — **v1.1**, не сейчас.

## Изменения в модели данных

**Удаляется:** `ChecklistList`, `ListItem`.

**`TaskItem` дополняется:** `folderId: UUID?`, `placeName: String?`, `address: String?`, `lat: Double?`, `lon: Double?`, `sortIndex: Int`, `sourceGoalId: UUID?` (для шагов, всплывших из цели).

**Новая `TaskFolder`:** `id, spaceId, title, subtitle?, template (shopping/watch/places/cities/empty), anyoneCanCheck: Bool, isPinnedShopping: Bool, sortIndex, createdByMemberId`.

**`Plan` → `Goal`** (переименование сущности и всех связей). **`PlanExpense` → `GoalExpense`.**

**Новая `GoalStep`:** `id, goalId, title, note?, isDone, doneByMemberId?, doneAt?, assigneeMemberId?, dueAt?, sortIndex`.

**Новая `BusyInterval`:** `id, spaceId, memberId, startAt, endAt, source (device/corbie), updatedAt`. Только интервалы, никакого текста.

**`Member` дополняется:** `sharesBusyTimes: Bool` (default false), `lastRecapSeenAt: Date?`, `lastUsVisitAt: Date?` (для бейджа).

**`Space` без изменений.**

## Изменения в виджетах

- `Shopping` теперь читает задачи из закреплённой папки Shopping.
- `Tasks` и `FreeTasks` фильтруют по `folderId == nil` по умолчанию (чистые задачи, без пунктов списков).
- `PlanProgress` → `GoalProgress`.
- Новый (опционально, если укладываемся): `FreeSlots` medium — ближайшие 2 общих свободных окна.

## Изменения в уведомлениях

Тип №10: **Weekly recap** (воскресенье 19:00). Итого 10 переключателей в настройках.

## Изменения в пейволле

Премиум: всё остальное, включая свободное время, папки задач, цели и подготовку.
